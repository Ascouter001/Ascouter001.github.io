Hexo介绍

Hexo是一款基于Node.js的静态博客框架。简单来讲：可以使用Markdown来写博客内容，Hexo会把这些纯文本的Markdown文件编译成HTML/CSS/JS等静态文件，最终生成一个可以直接部署到服务器/静态托管平台(如Github Pages)的完整博客网站。

Github Pages

Github Pages是Github提供的免费静态网站托管平台，就是说可以把静态网站的HTML/CSS/JS文件放到Github仓库里，Github会自动部署并提供一个可公开访问的网址，不用自己买服务器和配置环境。

3.检查是否真正启用了Github Pages

进行以下步骤启用Github Pages:

  • 进入仓库Settings
  • 左侧栏找到Pages
  • 确认：
    • Source: Deploy from branch
    • Branch: main
    • Folder: / (root)
