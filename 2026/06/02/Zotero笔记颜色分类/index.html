Zotero笔记颜色分类

在使用 Zotero 阅读论文时，高亮不仅仅是“把重要内容标出来”，更重要的是建立一套稳定的颜色规范。
如果每种颜色都有固定含义，后续回看论文、整理 Related Work、写实验分析或准备组会汇报时，就可以快速定位信息，而不用重新通读全文。

本文整理一套适合论文阅读和科研笔记的 Zotero 高亮颜色规范。

1. 为什么要统一高亮颜色？

很多人在阅读 PDF 时习惯看到重要内容就用黄色标出来。这样做一开始很方便，但读完几篇论文后会出现一个问题：

整篇文章到处都是黄色，最后反而不知道哪里真正重要。

因此，高亮颜色最好不要按照“好看”来使用，而应该按照“这段内容未来要如何被使用”来区分。

一套好的颜色规范至少应该满足三个目标：

  1. 快速回看：不用重读全文，只看颜色就能恢复论文结构。
  2. 方便写作：不同颜色可以直接对应论文写作中的不同部分。
  3. 辅助思考：不仅记录作者说了什么，也记录自己有什么问题和启发。

2. Zotero 高亮颜色推荐规范

颜色 中文含义 English Meaning 适合标注的内容
黄色 核心重点 / 主要结论 Key Point / Main Conclusion 论文主旨、核心观点、关键定义、作者最终结论
红色 问题 / 局限 / 反驳点 Limitation / Weakness / Critique 方法缺陷、实验不足、作者承认的 limitation、自己觉得有问题的地方
绿色 方法细节 / 技术路线 Method / Technical Design 模型结构、算法步骤、损失函数、训练策略、模块作用
蓝色 实验与结果 Experiments / Results 数据集、评价指标、baseline、实验设置、表格结论、消融实验
紫色 相关工作 / 可引用背景 Related Work / Background 综述性句子、领域背景、已有方法总结、适合写 Related Work 的内容
粉色 自己的灵感 / 可迁移点 Inspiration / Transferable Idea 可以借鉴到自己课题、比赛、论文中的想法
橙色 待处理 / 待验证 / 问题 To Check / Question 没看懂的公式、需要查代码的地方、想问导师或组会提问的点
灰色 次要信息 / 暂时保留 Secondary Note / Reserved 不是特别重要，但之后可能有用的背景、术语或补充说明

3. 最推荐的五种核心颜色

如果觉得八种颜色太多，最推荐先固定下面五种：

颜色 用途
黄色 这篇文章最重要的内容
绿色 这篇文章具体怎么做
蓝色 这篇文章如何证明方法有效
红色 这篇文章哪里存在问题
粉色 这篇文章对我有什么启发

这五种颜色基本可以覆盖大多数论文阅读场景。

尤其是在阅读机器学习、时间序列、多模态学习或智能体相关论文时，可以形成下面的习惯：

  • 黄色：标文章的核心贡献和最终结论。
  • 绿色：标模型结构、算法流程和关键模块。
  • 蓝色：标实验设置、结果分析和消融实验。
  • 红色：标局限性、失败案例和可能被质疑的地方。
  • 粉色：标自己可以迁移到课题中的想法。

4. 示例：读模型论文时如何使用颜色？

假设论文中出现下面几类句子，可以这样标注。

4.1 方法设计：绿色

We propose a cross-modal attention module to align EEG and fNIRS representations.

这句话描述的是模型中的一个关键模块，应该标为绿色。
绿色代表“方法细节”，后续写方法总结或复现模型时可以重点查看。

4.2 实验结果：蓝色

Our method achieves a 4.2% improvement over the strongest baseline.

这句话描述的是实验结果，应该标为蓝色。
蓝色代表“实验与结果”，后续整理表格、写汇报结论时很有用。

4.3 方法局限：红色

However, the model requires paired multimodal data during training.

这句话说明了方法的限制，应该标为红色。
红色可以帮助我们快速找到论文可能被质疑的地方，也适合用来准备组会提问。

4.4 可迁移启发：粉色

This suggests that frequency-domain features may complement temporal representations.

这句话可能启发我们在自己的任务中引入频域特征，因此可以标为粉色。
粉色不一定代表作者最重要的结论，而是代表“对我有用”。

5. 高亮使用原则

5.1 黄色不要用太多

黄色最好只标真正核心的 5%～10% 内容。
如果一篇论文一半内容都是黄色，那么黄色就失去了“重点”的意义。

5.2 不要把颜色含义频繁改来改去

颜色规范一旦确定，最好长期保持一致。
否则几个月后回看旧论文时，很难判断当时的颜色是什么意思。

5.3 高亮和文字笔记结合使用

颜色只能表示“类型”，但不能完全表达自己的理解。
对于真正重要的段落，最好在 Zotero 的 note 区补充一两句话，例如：

  • 这句话可以放到 Related Work。
  • 这个模块可以借鉴到我的 EEG-fNIRS 融合模型。
  • 这里的实验设置不够公平，后续可以作为提问点。

5.4 每篇论文读完后做一次颜色回收

读完一篇论文后，可以按颜色快速整理：

  • 黄色 → 论文主旨和贡献
  • 绿色 → 方法流程
  • 蓝色 → 实验结论
  • 红色 → 局限与问题
  • 粉色 → 对自己工作的启发

这样 Zotero 高亮就不只是阅读痕迹，而是可以直接转化为文献综述、组会汇报和论文写作素材。

6. 我的推荐工作流

一个比较适合科研阅读的 Zotero 工作流如下：

  1. 第一遍快速读摘要、引言和结论
    只用黄色和红色，先判断文章核心价值和明显问题。

  2. 第二遍读方法部分
    主要使用绿色，标出模型结构、算法流程和关键公式。

  3. 第三遍读实验部分
    主要使用蓝色，关注数据集、baseline、指标和消融实验。

  4. 最后回看全文
    用粉色标出对自己课题有启发的内容，用橙色标出还没弄懂的问题。

这种方式的好处是：
阅读不是一次性完成的，而是从“理解文章”逐步过渡到“利用文章”。

7. 颜色规范速查表

颜色 一句话记忆
黄色 这篇文章最重要的是什么
红色 这篇文章哪里有问题
绿色 这篇文章是怎么做的
蓝色 这篇文章怎么证明有效
紫色 这句话能不能写进 Related Work
粉色 这点对我的研究有什么启发
橙色 这里我还需要查什么
灰色 这段暂时保留，之后可能有用
