SCP命令使用笔记：Windows与Linux服务器双向传输文件

scp（Secure Copy）是一个基于 SSH 的文件传输命令，可以在本地电脑与远程服务器之间安全地复制文件。只要能够使用 ssh 登录 Linux 服务器，一般就可以直接使用 scp。

最重要的规则只有一条：第一个路径是来源，第二个路径是目标。

常用选项

选项 作用 示例
-r 递归复制整个目录 scp -r local-dir user@host:/path/
-P 指定 SSH 端口，注意是大写 P scp -P 2222 file.txt user@host:/path/
-i 指定登录使用的私钥 scp -i ~/.ssh/id_ed25519 file.txt user@host:/path/
-p 保留文件的修改时间和权限信息 scp -p file.txt user@host:/path/
-C 传输时启用压缩 scp -C large.txt user@host:/path/
-v 输出详细调试信息 scp -v file.txt user@host:/path/
