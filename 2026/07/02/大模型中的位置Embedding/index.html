大模型中的位置 Embedding

Transformer 里有一个很容易被忽略、但非常关键的问题：模型本身并不知道 token 的顺序。

在 RNN 里，文本是一个词一个词按时间步输入的，所以顺序天然存在；但 Transformer 的自注意力会同时看整段序列。如果不给它额外信息，我喜欢你 和 你喜欢我 在 token 集合上很接近，但语义完全不同。

所以大模型需要 位置 Embedding，也就是告诉模型：

本文整理三种常见方式：可学习位置 Embedding、正弦位置编码，以及 RoPE。

1. 为什么需要位置 Embedding？

Transformer 的核心结构是 Self-Attention。对于一个序列：

每个 token 都会和其他 token 计算注意力分数。这个机制很强，因为它可以直接建模长距离依赖；但它也带来一个问题：Self-Attention 本身对输入顺序不敏感。

如果我们只把词向量输入模型，模型看到的主要是“有哪些 token”，而不是“这些 token 按什么顺序排列”。

2.2 优点

可学习位置 Embedding 的优点是简单直接。

第一，参数含义清楚，就是一张位置向量表。

第二，它可以从数据中自动学习不同位置的统计规律。例如文本开头、句子中间、结尾位置可能具有不同模式，模型可以自己调整这些位置向量。

第三，实现成本很低，只需要像普通 embedding 一样查表再相加。

2.3 缺点

它最大的问题是泛化能力有限。

如果训练时最大长度是 2048，那么模型只学过 0 到 2047 这些位置。推理时如果输入长度超过 2048，就会遇到没见过的位置。

即使强行扩展位置表，新增加的位置也没有经过充分训练，效果通常不稳定。

所以可学习位置 Embedding 更适合上下文长度固定、外推需求不强的模型。

3. 正弦位置编码

正弦位置编码是原始 Transformer 论文中使用的方式。它不是训练出来的，而是用固定公式生成。

核心想法是：用不同频率的 sin 和 cos 函数给每个位置生成一个向量。

低维度对应较高频率，对局部位置变化更敏感；高维度对应较低频率，可以表达更长范围的位置变化。

3.2 为什么用 sin 和 cos？

正弦函数有两个很重要的性质。

第一，它天然可以生成连续、平滑的位置表示。位置 10 和位置 11 的编码不会突然完全无关。

第二，它有利于表达相对位置关系。因为三角函数满足一些变换关系，模型有机会从 pos 和 pos + k 的编码中学习到距离 k 的模式。

简单说，正弦位置编码不仅告诉模型“这是第几个位置”，也让模型更容易感知“两个 token 相隔多远”。

3.3 优点

正弦位置编码没有额外可训练参数，长度外推能力比可学习位置 Embedding 更自然。

因为任意位置都可以通过公式算出来，所以理论上推理时可以生成超过训练长度的位置编码。

它也很稳定，不依赖额外学习一张位置表。

3.4 缺点

它的缺点是表达能力相对固定。

位置编码由公式决定，不会根据具体数据自动调整。模型只能在后续层里学习如何使用这些固定编码。

另外，对于现代大模型来说，只把绝对位置向量加到 token embedding 上，往往还不够理想。大模型更关心的常常不是“当前位置是第 100 个”，而是：

4. RoPE：旋转位置编码

RoPE 全称是 Rotary Position Embedding，中文常叫旋转位置编码。

它和前两种方法最大的区别是：RoPE 不是简单地把位置向量加到 token embedding 上，而是在注意力计算里的 Q、K 向量上注入位置信息。

RoPE 的做法是：根据 token 的位置，对 Q 和 K 做一次“旋转”。

4.1 什么叫旋转？

可以把 Q 或 K 向量的相邻两个维度看成二维平面上的一个点：

如果这个 token 在位置 pos，就按照和 pos 相关的角度，把这个点旋转一下：

向量维度很高时，可以把它拆成很多个二维小平面，每一组维度都按不同频率旋转。

所以 RoPE 的“旋转”不是形象比喻，而是真的在向量空间里做旋转变换。

4.2 RoPE 如何体现相对位置？

RoPE 的巧妙之处在于：两个位置分别旋转后的 Q 和 K 做点积时，结果会自然包含它们的相对距离。

也就是说，如果一个 token 在位置 m，另一个 token 在位置 n，那么注意力分数里会出现和 m - n 有关的信息。

这非常适合语言模型，因为语言关系往往更依赖相对距离：

这些关系比“当前词的绝对编号是多少”更常用。

4.3 RoPE 和前两种方法的区别

可以简单对比：

方法 注入位置的方式 是否可学习 更偏向
可学习位置 Embedding 加到 token embedding 上 是 绝对位置
正弦位置编码 加到 token embedding 上 否 绝对位置，同时有相对位置线索
RoPE 旋转 Q、K 向量 否 相对位置

RoPE 不直接改变 V，也不是单纯给输入加一个位置向量。它改变的是注意力分数的计算方式，让“谁应该关注谁”这件事带上位置信息。

4.4 RoPE 的优点

第一，它天然适配注意力机制。位置关系直接进入 QK 点积，比只在输入层相加更贴近 Self-Attention 的核心计算。

第二，它能优雅地表达相对位置。对于大模型生成任务来说，这一点很重要。

第三，它在长文本场景里更常用。许多现代大语言模型都使用 RoPE 或 RoPE 的变体，并在此基础上做上下文长度扩展。

4.5 RoPE 的局限

RoPE 也不是完美的。

如果模型训练时主要见过短上下文，直接推理到极长上下文时，位置分布仍然会发生变化。实际工程中常见的 NTK scaling、YaRN、位置插值等方法，都是围绕 RoPE 的长上下文扩展问题提出的。

所以 RoPE 提供了更好的位置建模方式，但长上下文能力仍然需要训练数据、缩放策略和模型结构共同配合。

6. 小结

位置 Embedding 解决的是 Transformer 的顺序感问题。

可学习位置 Embedding 最简单，靠训练学出每个位置的向量，但外推能力较弱。

正弦位置编码用固定公式生成位置向量，不增加参数，能够自然生成任意长度的位置编码。

RoPE 则把位置信息注入 Q、K 的旋转中，让注意力分数天然包含相对位置信息，因此成为现代大模型中非常重要的位置编码方法。

理解这三者之后，再看 LLaMA、Qwen、ChatGLM 等模型里的位置编码设计，就会清楚很多。
